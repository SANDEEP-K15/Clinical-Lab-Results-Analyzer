# Download instructions for Kaggle dataset

#

# 2. Search for "Laboratory Test Results – Anonymized Dataset"
# 3. Download the dataset
# 4. Place the CSV file here as: laboratory_test_results.csv
# 5. Run: python scripts/preprocess_dataset.py
